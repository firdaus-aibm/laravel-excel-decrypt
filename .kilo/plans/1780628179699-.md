# Feature: Laravel v11/v12/v13 Support + `/init` Command

## Branch strategy
- **Base branch:** `dev` (has `withDecryptedFile` feature ahead of `main`)
- **Feature branch name:** `feature/laravel-multi-version-support`

## Task 1: Create `/init` Kilo Command

**File:** `.kilo/command/init.md`

Purpose: Minimal one-command setup for new contributors.

1. Check PHP version (require ^8.2)
2. Run `composer install`
3. Print a "ready" summary (PHP version, installed packages count, Laravel version constraint)

## Task 2: Widen Laravel Version Constraints

**File:** `composer.json`

Changes:
- `"php": "^8.1"` → `"^8.2"` (Laravel 11 recommends ^8.2; 12/13 will require ^8.2+)
- `"illuminate/support": "^11.0"` → `"^11.0|^12.0|^13.0"`
- `"orchestra/testbench": "^9.0"` → `"^9.0|^10.0|^11.0"`
- `"phpunit/phpunit": "^10.0"` → `"^10.5|^11.0"`

## Task 3: Update README

**File:** `README.md`

Add a "Version Compatibility" table:

## Task 4: Set Up CI (GitHub Actions)

**File:** `.github/workflows/tests.yml`

Matrix strategy:
- PHP: 8.2, 8.3, 8.4
- Laravel: 11, 12, 13

Steps:
1. Setup PHP with extensions
2. Composer install with locked Laravel version (via `composer require illuminate/support:^X.0 --no-update`)
3. Run PHPUnit

## Task 5: Compatibility Audit

Verify these files work across Laravel 11/12/13 with no changes needed (confirm during implementation):

- `src/LaravelExcelDecryptServiceProvider.php` — uses `ServiceProvider`, `publishes()`, `mergeConfigFrom()`. No signature changes across versions.
- `src/Facades/ExcelDecrypt.php` — extends `Facade`, uses `getFacadeAccessor()`. No changes.
- `src/ExcelDecryptionService.php` — uses `config()`, `storage_path()`, `file_exists()`. Pure PHP + Laravel helpers. No changes.
- `src/ExcelDecryptWrapper.php` — static method, no Laravel dependency. No changes.
- `src/Exceptions/ExcelDecryptException.php` — extends `\Exception`. No changes.
- `config/excel-decrypt.php` — plain PHP array. No changes.
- `tests/ExcelDecryptionServiceTest.php` — extends `Orchestra\Testbench\TestCase`. May need import updates if interface changes.

## Task 6: Verify

- Run `phpunit` locally (PHP 8.2 with Laravel 11 as baseline)

## Notes

- No breaking changes to the public API (`decryptFile`, `cleanupDecryptedFile`, `cleanupAllDecryptedFiles`, `getTempDirectory`).
- The `lib/` bundled libraries (PEAR, OLE, decryption engine) are pure PHP and version-agnostic.
- If any `orchestra/testbench` version introduces breaking changes to the test base class, the test file may need minor adjustments (e.g., `setUp()` signature).
